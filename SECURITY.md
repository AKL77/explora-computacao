# Política de segurança

## Versões cobertas

Somente a versão publicada na branch `main` recebe correções. Este protótipo
não possui backend, autenticação real ou banco de dados.

## Como relatar

Não publique credenciais, dados pessoais ou detalhes exploráveis em uma issue.
Use a opção **Report a vulnerability** na aba **Security** do repositório para
enviar um relato privado ao responsável. Inclua uma descrição do impacto,
passos mínimos para reprodução e a versão ou URL afetada.

Problemas sem impacto de segurança podem ser enviados pelo rastreador de
issues comum.

## Dados tratados nesta versão

A sessão demonstrativa, os favoritos e as pastas são armazenados apenas no
`localStorage` do navegador. O projeto não coleta credenciais, dados de
estudantes, analytics ou cookies de rastreamento. Links de recursos levam a
sites externos, sujeitos às políticas próprias desses serviços.
